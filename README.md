# Movie Library

ログイン制のブラウザ動画プレイヤー（PHP）

## 構成

```
movie-library/
├─ index.php    一覧 + プレイヤー
├─ login.php / logout.php
├─ stream.php   動画配信（ログイン必須・シーク対応）
├─ thumb.php    サムネイル（ログイン必須・自動生成）
├─ setup.php    初期設定（config.php が無い時だけ）
├─ config.sample.php  設定項目の見本
├─ lib.php
├─ .htaccess
├─ movie/       ← ここに MP4 を入れる（直接アクセス禁止）
└─ thumbs/      サムネイル自動保存先（直接アクセス禁止）
```

## 使い方

1. フォルダごとサーバーにアップロード
2. ブラウザでアクセスすると初期設定画面が出るので、サイト名・ユーザー名・パスワードを入力
   → `config.php` が自動作成され、そのままログインした状態になります（設定後は初期設定画面は使えません）
   ※ フォルダに書き込み権限が無い場合は、画面に表示される内容で `config.php` を手動作成
   （アップデートの zip には `config.php` を含めないので、上書きしてもログイン情報は消えません）
3. `movie/` に MP4 を入れる → 一覧に自動で出ます
4. `thumbs/` に書き込み権限（755 or 777）を付ける

## サムネイル

- サーバーに ffmpeg がある → サーバー側で自動生成
- 無い（レンタルサーバー等） → 初回表示時にブラウザが動画の5秒地点を切り出して保存
- 一度作れば次回からは即表示。動画を差し替えると作り直します

## 続きから再生（端末共通）

- 再生位置はユーザーごとにサーバーの `data/` に保存（10秒ごと・一時停止・シーク・タブを閉じた時）
- 同じユーザーでログインすれば、PC→スマホなど別の端末でも続きから再生
- 再開時は「○:○○ から再開しました [最初から]」を表示
- 一覧のカードに進捗バー・「続きから」「✓ 視聴済み」を表示（最後の15秒まで見たら視聴済み）
- `data/` に書き込み権限が必要

## 視聴画面・横画面ボタン

- 最初は一覧だけ表示。動画をタップすると視聴画面に切り替わり、「← 一覧」やスマホの戻るで一覧に戻る
- 動画左上の最大化ボタン（↖↘）で、スマホの回転ロック中でもすぐ横向き全画面に
- Android: 全画面にして画面の向きを横に固定
- iPhone: 全画面APIが無いため、プレイヤーを90度回転させて画面いっぱいに表示
- 横画面中は同じ位置の縮小ボタンで元に戻る（再生中に3秒操作が無いとボタンは消え、タップで再表示）

## Fire TV（テレビ）のリモコン操作

Fire TV の Silk ブラウザなどテレビで開くと自動でテレビ用の表示になります。

| リモコン | 一覧 | 再生中 |
|---|---|---|
| 十字キー | 動画を選ぶ（上で検索欄・ログアウト） | ◀▶ 10秒移動（連打・長押しで30秒→60秒）／▲▼ 再生バー表示 |
| 決定（真ん中） | 再生 | 再生／一時停止 |
| ⏯ ⏪ ⏩ | － | 再生／一時停止・10秒戻し・10秒送り |
| ▲ | － | 全画面のオン／オフ（アドレスバーを隠す） |
| ↩ 戻る | － | 一覧に戻る（見ていた動画にフォーカス） |

- 再生すると動画が画面いっぱいになり、下に タイトル・再生バー・時間・操作ボタン を表示（再生中は数秒で消える）
- リモコンとタッチ（マウス）は両方いつでも使える：画面タップでパネル表示/非表示、ボタンで ← 一覧・⏪10秒・再生/一時停止・10秒⏩・全画面、再生バーはタップ/ドラッグで移動
- 「○:○○ から再開しました」が出ている間に ▼ で最初から再生
- 端末名が分からないブラウザでも、マウスの無い端末（Echo Show 等）ならリモコンのボタンを押した時点で自動でテレビ表示に（以後記憶）
- それでも切り替わらない端末は URL に `?tv=1` を付けて開くとテレビ表示に（`?tv=0` で解除。端末ごとに記憶）
- PCでもキーボードの矢印・Enter・Esc で同じ操作ができます

## ログイン保持・再生の安定化

- 一度ログインすれば 60 日間ログインしたまま（使うたびに延長）。日数は config.php の `'login_days' => 60` で変更可
- セッションは `data/sessions/` に保存（共用サーバーの自動掃除で消えないように）
- 動画URLには24時間有効の署名が付くので、途中でセッションが切れても再生は止まらず、
  Cookie を送らないテレビ系ブラウザ（Fire TV など）でも再生できる
- 再生が途中で止まったら自動で最大3回再接続して、止まった位置から再開
- それでも再生できない場合は、動画の形式（H.265・10bit・AC3音声など）を調べて原因と変換コマンドを表示
  （サーバーに ffprobe が必要。無い場合は一般的な案内のみ）

## 直接アクセス対策

- `movie/` は `.htaccess` で全拒否 → `/movie/xxx.mp4` を直接開いても 403
- 再生は `stream.php?f=...` 経由で、ログインしていないと 403
- より安全にするなら `movie/` を公開ディレクトリの外に置き、`config.php` の `movie_dir` をそのパスに変更
- nginx の場合は `.htaccess` が効かないので `location /movie/ { deny all; }` などを設定

※ ログイン中のユーザーが画面録画やブラウザの開発ツールで保存することまでは防げません。

## GitHub から自動アップロード（FTP）

`main` に push すると、変更したファイルだけがサーバーへ FTPS で自動アップロードされます（`.github/workflows/deploy.yml`）。

- Settings → Secrets and variables → Actions の **Secrets** に `FTP_SERVER` / `FTP_USERNAME` / `FTP_PASSWORD` / `FTP_DIR`（末尾 `/`）
- **Variables** に `FTP_DEPLOY` = `true`（これが無い間は動かない。止めたい時は true 以外に）
- 動画・サムネイル・config.php・視聴履歴は Git に入れずアップロードもしないので、本番のものは消えません
